**What is CareStream?**

CareStream is a prototype web platform for live patient health monitoring. Doctors and nurses can monitor vital signs (heart rate, oxygen levels, etc.) in real time. It connects with physical/simulated sensors (ESP32/MAX30102), uses Scikit-Learn (Isolation Forest) for automated anomaly detection, sends alerts, and enforces role-based access control so only authorized staff can access patient data. It was deployed using AWS ECS, AWS RDS, and Vercel.

It was built as a production-oriented Python backend project, demonstrating modern async architecture, a secure full refresh-token authentication system, PostgreSQL with SQLAlchemy 2.x/Alembic, Redis, Celery, Docker, pytest, Locust, and CI/CD with code quality tooling. It is currently in active development.

**What is the microservices platform?**

It is a backend trading/market platform built using a polyrepo microservices architecture. It includes an authentication service, a market service, and shared infrastructure (PostgreSQL, Redis, Docker, Celery). Each service owns its own PostgreSQL schema within a shared database instance. Services communicate over a shared Docker network. Additional services (strategy, risk, analytics, API gateway) are planned but not yet implemented.
